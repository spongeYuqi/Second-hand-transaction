## 综述

### 本项目简介

作为专门为校内服务的二手仓小程序，初衷就是快速进行绿色交换，一个纯粹二手交易发布信息的发布平台，最终的交易为用户之间直接加联系方式进行；并没有做留言，私信，点赞和线上支付等功能，一是因为学校内部就已经拥有了一个非常棒的小程序，能方便我们学生进行交流娱乐等，而我只是细分了一个二手的功能；二是因为我作为个人，非企业，还没有相关权限，资金也不够支撑；三是因为我个人精力有限，运营安全方面无法顾及。

### 主要修改点（可参考原作者源码地址说明）

1.原项目是专注二手书籍的交易，本项目扩展为多个类目。 2.因为专注校园内部，不收取中间费，取消了线上支付功能及订单管理功能，删除了所有相关的文件及云函数。 3.首页每个商品 or 需求的信息展示内容及排版。 4.发布步骤一更改为类别标签选择；步骤二更改了详情填写（详情信息、图片、联系方式、价格）。 5.注册登录更改为不直接获取微信生态的用户信息，而是用户自填写，靠 openid 进行唯一标识。 6.云开发数据库集合（banner 广告、publish 发布、start 启动图、user 用户）
